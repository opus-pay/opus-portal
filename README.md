# opus-portal

**OPUS Portal**: OPUS 에스크로 위에서 만든 서비스를 모아 보여 주는 사이트입니다. 서비스를 나열하고 지갑을 연결할 뿐, **사람을 연결하지도 돈을 맡지도 않습니다** (결정 D24).

```
┌──────────────────────────────────────────────┐
│ OPUS                     [언어] [지갑 연결]  │  ← 위: WalletConnect
├──────────────────────────────────────────────┤
│                                              │
│   OPUS 위에서 만든 서비스                    │
│   ┌────────┐ ┌────────┐ ┌────────┐           │  ← 가운데: 서비스
│   │WayHand │ │OPUS    │ │OPUS    │  …        │     WayHand는 링크,
│   │ 이용   │ │Class   │ │Asset   │           │     나머지 8개는 준비 중
│   └────────┘ └────────┘ └────────┘           │     (선택되지 않음)
│                                              │
├──────────────────────────────────────────────┤
│        백서   아키텍처   GitHub              │  ← 아래: 링크
└──────────────────────────────────────────────┘
```

정적 사이트입니다 (`next build`가 `out/`을 만듭니다). 서버 코드가 없어서 키나 사용자 데이터를 가질 수 없고, 어떤 파일 호스팅이나 IPFS 미러로도 올릴 수 있습니다 (ROADMAP #66).

## 실행

```bash
yarn install
cp .env.sample .env.local     # 값을 채웁니다
yarn dev                      # http://localhost:3200
yarn test && yarn lint && yarn formatting:check
yarn build                    # out/
```

Node 22 이상이 필요합니다.

## 설정 (`.env.local`, 빌드할 때 읽힘, 비밀이 아님)

| 설정                                   | 뜻                                                                                                                                              |
| :------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------- |
| `NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID` | [cloud.reown.com](https://cloud.reown.com)에서 무료로 받는 프로젝트 ID. 비우면 브라우저 지갑만 됩니다. 허용 주소 목록에 사이트 주소를 넣으세요. |
| `NEXT_PUBLIC_SITE_URL`                 | 이 사이트의 주소 (지갑에 표시됨)                                                                                                                |
| `NEXT_PUBLIC_WAYHAND_URL`              | WayHand의 주소. 비우면 `https://wayhand.net`입니다.                                                                                             |
| `NEXT_PUBLIC_GITHUB_URL`               | 아래쪽 GitHub 링크 (기본 `https://github.com/opus-pay`)                                                                                         |
| `NEXT_PUBLIC_DOCS_URL`                 | 백서·아키텍처 문서가 있는 곳 (기본 `https://github.com/opus-pay/opus-osx/blob/main`)                                                            |

## 지갑 연결에 대해

-   **연결만 합니다.** 서명도 거래도 요청하지 않고, 연결하면 주소만 보입니다. (네트워크 페이지의 버튼은 사용자가 누를 때만 지갑에 네트워크 추가·전환과 USDC 표시를 요청하며, 돈이 움직이지 않습니다.) 이후 "내 작업(여러 서비스에 걸쳐)"(#64) 같은 화면이 이 주소로 체인을 읽게 됩니다.
-   브라우저 지갑과 WalletConnect가 모두 있으면 메뉴에서 고르고, 하나뿐이면 바로 연결합니다. 체인은 Polygon과 Polygon Amoy입니다.

## 서비스는 어떻게 목록에 오르나

**문의와 계약으로만 오릅니다 (D23, 2026-10-07 결정).** 체인에서 자동으로 읽거나 누구나 등록하는 방식은 쓰지 않습니다. 열린 등록은 스팸, 진짜 서비스를 베낀 가짜, 사기를 막지 못하기 때문입니다.

1. 서비스 쪽이 운영자에게 연락합니다 (화면에 문의 버튼은 두지 않았습니다).
2. 운영자가 누가 운영하는지, 인스턴스 주소, 하는 일을 확인하고 조건에 합의합니다.
3. 합의한 서비스를 `src/lib/services.ts`에 한 항목으로 더하는 PR을 올립니다. 모든 변경이 공개 기록으로 남습니다.
4. 서비스가 수정이나 삭제를 요청할 수 있고, 운영자는 노출 정책(#66)에 따라 내릴 수 있습니다.

## 원칙

-   **중립:** 서비스를 나열할 뿐 순위를 사지 않고, 팀 서비스를 고정하지 않습니다 (ROADMAP #63). 노출 정책과 신고 처리는 #66에서 정합니다.
-   **준비 중인 서비스는 선택되지 않습니다.** 포커스도 클릭도 텍스트 선택도 안 되고, 화면 읽기 도구에는 "아직 열리지 않았습니다"로 읽힙니다.
-   **백서·아키텍처 링크는 `opus-osx` 저장소를 가리킵니다.** 그 저장소가 비공개인 동안에는 로그인하지 않은 방문자에게 열리지 않습니다. 공개하거나 `NEXT_PUBLIC_DOCS_URL`을 바꾸세요.

## 아직 안 한 것

등록 조건 문서와 노출 정책(#62, #66), 등록된 서비스의 온체인 통계(#63), 내 작업(#64), 평가자·중재인 목록(#65), 노출 정책과 IPFS 미러(#66). 지금은 목록을 코드에 적어 두는 첫 화면입니다.
